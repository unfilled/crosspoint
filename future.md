## 1a. UX-итерация 2026-11-13 (пожелания после тестирования на устройстве)

- [x] **fb2 исключён из библиотечного индекса** (`isLibraryBookFile`):
      парсинг полки с тысячами fb2 занимал минуты. Побочный эффект: cover-grid
      home строится из индекса — fb2 там не появятся (Recents остаются).
- [x] **Home/прогресс не конвертируют fb2 синхронно**: `Fb2::cachedEpub`
      (новый, только кэш) вместо `ensureEpub` в `coverContentPath` и
      `loadBookProgress` — после Clear Cache home больше не фризится на
      пакетной конвертации recents; обложка/прогресс появятся после первого
      открытия книги.
- [x] **Действие по тапу на слово** (настройка «спросить/словарь/вырезка/
      закладка», `selectionDefaultAction`): тап по слову выполняет выбранное
      действие сразу, без тапа по панели. Long-press-выделение фраз всегда
      показывает панель.
- [x] **Файловый менеджер возобновляется** (`browserLastPath`/
      `browserLastEntry` в state.json): вход через Home открывает папку и
      выделение последней открытой книги; явные пути (возврат из просмотрщика
      картинок) не затрагиваются.
